# Fahad Malik — personal website

A hand-drawn, film-inspired personal website. This is a personal introduction, not a project showcase.

## Stack

- React + JavaScript
- Vite
- Tailwind CSS 4
- Lucide React
- Custom CSS, SVG illustrations and motion

## Run locally

\`\`\`bash
npm install
npm run dev
\`\`\`

## Build

\`\`\`bash
npm run build
npm run preview
\`\`\`

The opening sequence can be skipped. It remembers completion for the current browser session. Sound is not forced; the sound control is intentionally a visual placeholder until a real sound layer is added.
